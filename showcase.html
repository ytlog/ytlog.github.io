CHAPTER I 运行时

ART DCEVM

Android 运行时类重定义增强库：应用运行中修改字段、方法、修饰符与继承关系，无需 root，不改系统分区。

运行中修改 Android 类结构

01特性

  • 字段、方法、构造器的新增、退役与恢复，字段类型与方法签名变化
  • 接口演进：新增 default/static 方法与父接口，与实现类同批原子提交
  • 已有对象保留兼容字段值；不支持的变化整批拒绝，旧定义不受影响
  • 以 ART 自带的结构重定义事务为引擎，只接管校验、成员映射与类分配

CHAPTER IV 开发工具

Compose Hot Reload

为 Android Compose 应用提供热重载：修改 Kotlin / Java 代码、Compose UI 与资源后，无需重装 APK、无需重启进程，即可应用到正在运行的 App。

Android Compose 热重载

01特性

  • 编辑 Compose UI 与函数实现，编译后直接在运行中的 App 里看到结果
  • 支持修改已有的字符串、颜色、图片与 assets 等 Android 资源
  • 基于 art-dcevm 在 ART 上重定义类，支持字段、方法与接口的增删改
  • Gradle 插件接入；--auto 模式保存即重载，失败原因在 devtools 中查看
